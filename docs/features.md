# 功能说明

[← 返回文档目录](../README.md#-文档)

各模块的完整细节。概览和信息源列表见 [README](../README.md#-功能)。

## 采集

- cron 每 10 分钟检查一次，各来源按自己的采样间隔（10 分钟～6 小时）采集，失败的 20 分钟后重试。
- GitHub Trending 和 HF 模型热榜另记每天的名次。
- X 不用付费 API：从 AINews 日报取每天按互动量排的热帖，帖子原文用官方 oEmbed 读。

## 事件、排序与简报

- 事件合并：规则聚类 + DeepSeek 合并同一件事，事件持久化有固定 id。
- 排序：规则分（兴趣、来源、多源、热度）× 模型给的重要性。
- 每个事件有 AI 简报（先读主来源原文，写概要和要点，不用点开链接也知道主要内容）和 AI 解读（新在哪、可能的影响、值得留意的局限，和只写事实的概要分开）。
- App 上的英文来源标题都翻成中文。
- 未追踪信息：热度高但和你无关、没放进首页的事，可以点“想看这类”纠正。

## 论文专题

- 论文的见报时间是投稿时间，arXiv 隔一两天才公布、周末不公布，采到时多半已经在信息流的 72 小时时间窗之外，所以论文另有一个专题，看最近一周。
- 每篇新论文由模型对照你的记忆判断和你的关系（3 = 值得扫一眼，4 = 值得读，5 = 正好对上你在做的事、建议精读），写一句为什么；每篇只判一次。
- 值得读的论文写简报：读全文开头，按“做了什么、方法、结果（带数字）、局限”写，每轮最多 6 篇。
- 按记忆主动去找：每 12 小时按最强的几条“正在做 / 长期关注”的英文关键词去 arXiv 全站搜最近一周的论文，补上配置的分类（cs.CL、语音）之外的，比如 Agent、编码方向的论文。
- 专题页三个列表左右滑：为你挑的（写着和你的关系，“精读”的有标签）、社区热门（HF Papers 点赞）、最新；右上角“问一问”问这一周的论文。
- 论文只推重要的（重要性 4 以上才进信息流、推送），一般的留在论文专题里。

## 推送

- 能推的都推：模型判定为新闻、还没推过的事件，不限条数；排在后面但正热门的新闻也会判断。
- 只出现在 GitHub Trending 等榜单或创投媒体上的，要模型判为“重要”才推送、才进信息流，一般的留在专题里。
- 不感兴趣的在首页右滑“不需要”，从反馈里学。
- 23:00～8:00 只推重要性 5 的重大消息，其余早上合成一条早报。
- 持续追踪：主动搜后续，只推实质进展。
- 经推送 hub（独立的 infofeed 服务，不在本仓库）送达。

## 报告

- 每个自然日、周、月结束后写一份，周报月报由日报汇总，写好后推送一次。
- 每份先是“观察”：挑出几件大事，找来 HN、Reddit 评论、X 热帖、网上的分析和这段时间的专家博客，加上你是谁、这几天问过什么，用 deepseek-v4-pro 打开思考写开头的判断、几条观察（判断、依据、不同看法、引语）、大家怎么看、和你有关、接下来盯什么；引语的出处和链接由代码按材料填，不让模型编。
- 后面才是要点和分领域的清单。

## 对话与分享

- 对话：事件下提问（先读原文、标注出处、流式输出），或直接问自己的事件库。
- 读论文：论文下提问时读 arXiv 的 HTML 全文（去掉参考文献，约 5 万字以内），按陪读的方式回答：标出处到哪一节、哪张表，公式讲直觉，分开作者的说法和看法（基线是否公平、规模、消融、局限），再说和你有什么关系；建议问题是“用几句话讲清这篇论文”“实验结果靠得住吗”“对我在做的事有什么可以借鉴的”。
- 问事件库时，和你有关、还没写简报的论文也算，可以直接问“这周有哪些和我有关的论文值得读”。
- 替你留意的问题：对话里暂时没答案的问题，之后有报道回答了就写回原对话并推送。
- 分享到 Catchup：系统分享或复制链接，读原文、归入事件、写简报，不会再推回给你。

## 记忆

- 对话、反馈、漏报沉淀为六类记忆：正在做 / 长期关注 / 不想看 / 偏好来源 / 不想看的来源 / 写法；可查看编辑删除，可整体关闭。
- 每条有强度，被你的行为印证就加强，长期关注久不印证会淡化（排序权重随之降低）；换个说法的同一件事不重复记，每天整理一次、合并重复的。
- 会主动问一句（信息流顶部的小卡，每天最多一个，模型照着你跳过的那几条写成随口一问）：好像不再关注的长期关注问“还关注吗”，快到期的正在做问“还在做吗”，答了当场生效。
- 记忆驱动：排序加权和简报的重要性判断参考记忆；记忆变化后重写前排简报（每轮先推新消息，推完再分批重写，不耽误推送）。

## 反馈学习

- “不需要”时选原因：模型列出几类可能不想看的内容由你选（选中的原样记下），或者这个来源 / 已经知道了 / 其他。选了的当场记下、撤回时一起删；“其他”和没选原因的先存档，攒几条一起找共同点。
- 追踪、提问、评分等主动行为记入行为日志，最多每 6 小时按规律归纳一次（至少两件事、足够分量的主动行为支撑）。
- App 还上报信息流和专题里显示过哪些（专题页露出一半以上才算）、打开详情从哪进来、停留多久、读到多深；这些“只是看过”的只加强或减弱已有记忆，不会生成新记忆。

## 安卓 App

- 首页分“信息流”“专题”“报告”三页，左滑下一页、右滑上一页。
- 信息流：按见报时间从新到旧、按天分组，每天先是分数最高的 3～5 件“最值得看”，一件一张雾面金属的大卡片（流动的颜色带金属光泽和颗粒，见 [设计](design.md)）：有封面的大图在上面、下半截融进流动的模糊封面，没有封面的是这个话题的颜色生成的抽象封面；颜色随信息流一起来，卡片一出来就是最终的颜色，图下来时淡入。其余按时间排成一条线（磨砂的行，重要性 3 以上带一行概要），有封面的带小图，话题写成文字，最重要的标“要闻”，滑到底加载更早的。每一页的底是一层流动的雾，首页是珍珠银。
- 专题：话题专题（AI 语音 / 大模型 / Agent / AI 创投）收这个话题的全部事件（包括没进信息流的一般动态）和榜单上的相关条目；论文专题见上面；榜单专题（GitHub Trending / HF 模型热榜 / Product Hunt）按名次列全部条目，HF 模型点开是模型页（中文简介、参数量、精度、许可证、基座模型，有事件的可以跳过去）；专题卡片是这个话题颜色的雾面金属，点开的专题页标题栏是同一张图，整页的底是同色的雾。
- 报告：日报 / 周报 / 月报左右滑切换，往下滚到底接着出上一期。
- 手势与动效：榜单的几个分类、报告的几种周期左右滑切换时，相邻的一页跟着手指进来，标签胶囊跟着走，两头有橡皮筋；点开消息、专题卡片时卡片原地展开成整页，关闭时收回列表里那张卡片；其余二级页面从右边推进来、右滑返回（下面那页带视差）；底部面板从下面升起、下拉收起；松手都接着手指的速度，内容更新时淡入、其余平滑让位。
- 记忆页画成气泡：越大越强，越亮越近被印证，快忘了的变淡下沉；打开时依次浮上来、平时轻轻漂浮，最近被印证的有呼吸光环，删除时破掉；点气泡可改可删。
- 详情页（概要 + 要点 + AI 解读 + 来源；论文多一段“和你的关系”）：一张白纸，不用方框；从彩色卡片点开时头部接着卡片的流动封面，颜色不均匀地往下淌进正文；“想多看”（详情页按钮或在信息流里双击，冒出心形，提示记住或加强了哪条记忆）；右滑“不需要”（追踪中的行右滑取消追踪、不再显示答案）；下拉刷新；设备自动绑定。
- 故障提示：几个来源同时连续采不到内容（多半是网络或代理断了）、单个来源 6 小时没采到或采集停了，首页顶部就出一条小红条“服务疑似故障：…”。
